# Optimal Binary Search Tree

A Python implementation of the **Optimal Binary Search Tree (OBST)** dynamic-programming algorithm for a small set of ordered keys.

## What it demonstrates

- Successful-search probabilities (`p`) and unsuccessful-search probabilities (`q`)
- Weight, expected-cost, and root tables
- Dynamic programming over increasing interval lengths
- Minimum expected search cost for the example

## Run

The implementation is in the `Successful Search` file. Run it with Python 3:

```bash
python "Successful Search"
```

The sample input is defined in the source file; edit the keys and probability arrays to experiment with other examples.
